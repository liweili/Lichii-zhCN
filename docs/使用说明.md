# 使用说明（最终用户）

## 你会拿到什么

一个 zip：`release/Lichii-zhCN-v0.1.0.zip`。解压后：

```
languages/
  ├─ zh_CN.qm          ← 中文语言包（插件本体，约 234 KB）
  └─ README.txt
安装说明.txt
patch/
  └─ external-language-loader.patch
README.md / CHANGELOG.md / LICENSE.txt
```

## 步骤

### 1. 确认 Lichii 是否支持外部语言包

- 打开 Lichii → 设置 → 界面 → 语言，看下拉里**除 `<系统>` / `English` 之外**还有没有别的语言项。
- 有 → 说明这个构建已内置加载补丁，跳到步骤 3。
- 没有 → 说明是官方原版或普通构建，需要先做步骤 2。

### 2.（仅首次）让 Lichii 支持外部语言包

需要一份源码和一次编译。按上游 `docs/Build.md` 准备依赖，然后：

```bash
git clone --depth 1 -b nx2 https://github.com/zortos293/Lichii.git
cd Lichii

# 方式 A：项目脚本（推荐，会备份、可还原）
python <本项目>/tools/apply_patch.py --source . --check
python <本项目>/tools/apply_patch.py --source .

# 方式 B：git apply
git apply <本项目>/patch/external-language-loader.patch

# 按上游构建指南编译，不需要开 ENABLE_QT_TRANSLATION
cmake --build build --parallel
```

编译产物仍是 `lichii.exe`（Windows）/ `lichii`（Linux）。这一步只需做一次，
以后换语言包不用再编译。

> 如果不想自己编译，也可以使用社区已经内置该补丁的构建。本项目不提供 Lichii 主程序。

### 3. 安装语言包

把 zip 里的 `languages/` 整个文件夹放到 **lichii.exe 同级目录**：

```
D:\Lichii\
  ├─ lichii.exe
  ├─ ...
  └─ languages\
       └─ zh_CN.qm      ← 放这里
```

或在本地项目里用脚本：

```bash
python tools/install.py --target "D:/Lichii"
```

### 4. 选择中文

1. **重启 Lichii**（首次放入新 `.qm` 必须重启，下拉列表在启动时枚举目录）。
2. 设置 → 界面 → 语言 → 选 `Chinese (China)`（中文系统下可能显示为`中文(中国)`）。
3. 界面立即切换为简体中文，不用再重启。

### 5. 更新 / 卸载

- **更新**：用新版 `zh_CN.qm` 覆盖旧文件，重启 Lichii。
- **卸载**：删掉 `languages/zh_CN.qm`，或 `python tools/install.py --target "D:/Lichii" --uninstall`。
- **临时切回英文**：在语言下拉里选 `English` 即可，不用删文件。

## 排查

| 现象 | 处理 |
|---|---|
| 下拉里没有中文项 | ① 程序未打补丁；② `.qm` 不在 exe 同级 `languages/`；③ 文件名不是 `zh_CN.qm`；④ 放完文件没重启 |
| 选了中文但界面没变 | 确认选的是 `zh_CN` 而不是其它 locale；切换后 `retranslateUi` 应即时生效，个别窗口需重开 |
| 个别文字仍是英文 | 上游新增了文案，语言包还没收录；Qt 会回退显示英文，属正常行为 |
| 中文显示成方框 | 系统缺少中文字体，安装系统中文字体包 |
| 补丁脚本报「锚点未匹配」 | 上游代码已变化，按 `patch/README.md` 重新生成 diff 或手工合并 |

## 注意

- 语言包只影响界面文字，不影响游戏内容、模拟器设置与兼容性。
- 本包不含任何游戏 ROM、固件或密钥。
- 游戏内的文字由游戏自身资源决定，不会被界面语言包翻译。
