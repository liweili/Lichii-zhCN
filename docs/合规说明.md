# 合规说明

## 项目定位

Lichii-zhCN 是面向 [zortos293/Lichii](https://github.com/zortos293/Lichii) 的**第三方、独立**简体中文界面语言包。
不隶属于 Lichii、Eden、Eglantine、yuzu、Sudachi 或任天堂，也不代表其官方立场。

## 遵守的上游规则

在动手前已检索上游仓库（`nx2` 分支，2026-11-09）：

1. `dist/languages/README.md`
   - 该目录与 Eden 的 Transifex 项目同步；
   - 译文贡献应通过 Transifex 提交；
   - 译者须保证译文准确、不含违规或夹带内容；
   - 「New language requests will not be honored for the time being」——不给上游新增语言，本项目选择做独立语言包，不占用上游语言列表。
2. `CONTRIBUTING.md`
   - Issue / PR 应发到 `zortos293/eglantine`；
   - 改动保持聚焦，说明测试范围，区分编译检查与实际游戏测试。
3. `AGENTS.md` / `docs/Coding.md`：上游编码与协作约定。
4. `LICENSE.txt` 与源文件 SPDX：`GPL-3.0-or-later`。

本项目**没有**向任何上游仓库创建 Issue、分支、提交或 PR；也没有执行仓库文档里要求运行的构建/测试命令（编译 Lichii 由用户自行完成）。

## 交付物边界

| 包含 | 不包含 |
|---|---|
| `.ts` / `.qm` 译文数据 | Lichii 主程序、安装包或补丁后的 exe |
| 纯文本 C++ diff（用户自行应用） | 对上游仓库的直接写入 |
| 构建、安装、验证脚本 | 游戏 ROM / 固件 / 密钥 / `prod.keys` |
| 文档与许可说明 | 任天堂受版权保护的任何素材 |

补丁只改界面语言加载路径，不改模拟逻辑、不加网络请求、不读取用户数据、不访问仓库外文件。

## 许可证

- 补丁与工具：GPL-3.0-or-later；
- 译文数据：继承上游 `dist/languages/zh_CN.ts` 的版权与许可，本项目补充部分同样以 GPL-3.0-or-later 提供；
- 详见根目录 `LICENSE.txt`。

## 回馈上游

若希望把补译的文案合并进官方语言包，请读者自行：

1. 到 [Eden Transifex](https://app.transifex.com/edenemu/eden-emulator) 提交译文（这是上游指定的翻译贡献渠道）；或
2. 按 `CONTRIBUTING.md` 到 `zortos293/eglantine` 开 Issue / PR，并遵循其模板与审查要求。

本项目不代替用户执行上述动作。
